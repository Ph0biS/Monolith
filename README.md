## ⚡ Основной Функционал (Core Features)

* **💻 Cyberpunk UI & Bootloader**
  Кастомная оболочка с анимированным терминалом загрузки (`MONOLITH_OS_BOOT`), эффектами неонового свечения (Neon Glow) элементов управления и глубокой темной темой.
* **📥 Раздельный учет транзакций**
  Интуитивное переключение режимов «Доход» / «Расход» с динамической изоляцией списков категорий для предотвращения ошибок ввода.
* **🧠 ИИ-Ассистент Atlas**
  Локальный аналитический модуль, генерирующий контекстные подсказки, предупреждения об аномальных тратах и подбадривающий пользователя при достижении целей.
* **📊 Интерактивная Аналитика**
  Динамические круговые диаграммы (*Microcharts / SkiaSharp*) с консистентным кодированием цветов (цвета на графике полностью совпадают с прогресс-барами и списками).
* **🎯 Цели и Копилки**
  Визуальный трекер сбережений с индикаторами выполнения (`ProgressBar`) и возможностью мгновенного пополнения ракетным депозитом `🚀`.
* **💳 Менеджер Подписок**
  Контроль регулярных списаний (сервисы, софт, связь) с отображением точной даты платежа в формате `dd/MM`.
* **💱 Мультивалютное ядро**
  Интеграция с внешним API курсов валют для мгновенного пересчета баланса (RUB, USD, EUR) в реальном времени.

## 📖 Инструкция Оператора (User Guide)

1. **Инициализация Ядра:** При запуске приложения дождитесь завершения логов симуляции загрузки терминала на стартовом экране (`MONOLITH_OS_BOOT`). До полного завершения процесса интерфейс заблокирован.
2. **Добавление Записей (Изоляция потоков):**
   * Форма ввода находится в нейтральном состоянии. Поле выбора категорий изначально пустое.
   * Нажмите кнопку `💸 РАСХОД` или `💰 ДОХОД` — интерфейс мгновенно переключит контекст, активирует выпадающий список и подгрузит строго отфильтрованные категории (чтобы исключить ошибочное добавление «Зарплаты» в расходы).
   * Введите числовое значение суммы, добавьте краткое описание для логирования и нажмите `ДОБАВИТЬ ЗАПИСЬ`.
3. **Протокол Накоплений:** При создании финансовой цели укажите желаемую финальную сумму. Пополнение счета копилки осуществляется быстрым тапом по кнопке ракетного депозита `🚀`. Достижение лимитов разблокирует скрытые ачивки ядра (например, статус *Сберегатель 💰*).

## 🚀 Инструкция по Установке и Сборке

### Системные требования
* **IDE:** Visual Studio 2022 (с установленной рабочей нагрузкой `.NET MAUI`) или VS Code с плагином *.NET MAUI Extension*.
* **SDK:** Наличие установленного `.NET SDK 8.0` или `.NET SDK 9.0`.
* **Важно для Apple сред:** Для компиляции под macOS/iOS физически необходим компьютер Mac с развернутым актуальным **Xcode**.
