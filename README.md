**Monolith** — это футуристический кроссплатформенный финансовый менеджер, созданный на базе фреймворка **.NET MAUI** (C# / XAML). Приложение объединяет в себе строгий контроль личного бюджета, продвинутый анализ данных под управлением ИИ-помощника **Atlas**, систему геймификации и кастомный неоновый интерфейс в стиле *Synthwave / Y2K*.

> 🤖 **Цитата дня от Atlas AI:** > *"Система активна. Все твои копилки закрываются строго по графику. Баланс подписок стабилен. Отличный уровень контроля, продолжаем движение!"*

---

## ⚡ Основной Функционал (Core Features)

* **💻 Cyberpunk UI & Bootloader:** Кастомная оболочка с анимированным терминалом загрузки (`MONOLITH_OS_BOOT`), эффектами неонового свечения элементов управления и поддержкой темного режима.
* **📥 Раздельный учет транзакций:** Интуитивное переключение режимов «Доход» / «Расход» с динамической изоляцией списков категорий для предотвращения ошибок ввода.
* **🧠 ИИ-Ассистент Atlas:** Локальный аналитический модуль, генерирующий контекстные подсказки, предупреждения об аномальных тратах и подбадривающий пользователя при достижении целей.
* **📊 Интерактивная Аналитика:** Динамические круговые диаграммы (*Microcharts / SkiaSharp*) с консистентным кодированием цветов (цвета на графике полностью совпадают с прогресс-барами и списками).
* **🎯 Цели и Копилки:** Визуальный трекер сбережений с индикаторами выполнения (`ProgressBar`) и возможностью мгновенного пополнения ракетным депозитом `🚀`.
* **💳 Менеджер Подписок:** Контроль регулярных списаний (сервисы, софт, связь) с отображением точной даты платежа в формате `dd/MM`.
* **💱 Мультивалютное ядро:** Интеграция с внешним API курсов валют для мгновенного пересчета баланса (RUB, USD, EUR) в реальном времени.

📖 Как пользоваться системой
Инициализация: Дождитесь окончания симуляции загрузки ОС во время стартового экрана.

Добавление записи: * Форма ввода изначально находится в нейтральном состоянии.

Нажмите кнопку 💸 РАСХОД или 💰 ДОХОД — поле выбора категорий автоматически активируется и подгрузит нужный список.

Введите сумму, описание и нажмите ДОБАВИТЬ ЗАПИСЬ.

Управление Копилками: Создайте цель, указав сумму, и пополняйте её тапом по кнопке 🚀. При накоплении крупных сумм система начислит скрытые ачивки (например, Сберегатель 💰).

## 🚀 Инструкция по Установке и Запуску

### Системные требования
1. **IDE:** Visual Studio 2022 (с рабочей нагрузкой `.NET MAUI`) либо VS Code с установленным *.NET MAUI Extension*.
2. **SDK:** `.NET SDK 8.0` или новее.
3. **Окружение:** Для сборки под macOS/iOS необходим компьютер Mac и установленный актуальный **Xcode**.

### Быстрый старт из терминала
```bash
# 1. Клонируйте репозиторий
git clone [https://github.com/YOUR_USERNAME/Monolith.git](https://github.com/YOUR_USERNAME/Monolith.git)
cd Monolith

# 2. Восстановите зависимости NuGet
dotnet restore

# 3. Запустите проект на нужной платформе
# Для macOS (Mac Catalyst):
dotnet build -t:Run -f net8.0-maccatalyst

# Для Android:
dotnet build -t:Run -f net8.0-android

# Для iOS (в симуляторе):
dotnet build -t:Run -f net8.0-ios
