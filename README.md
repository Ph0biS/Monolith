**MONOLITH** — это футуристический кроссплатформенный финансовый менеджер, построенный на **.NET MAUI (C# / XAML)**.<br>
Строгий контроль бюджета. Продвинутая аналитика под управлением ИИ-ассистента **Atlas**.<br>
Геймификация. Трекер долгов. Личный журнал. Неоновый интерфейс в стиле *Synthwave / Cyberpunk*.

## ⚡ Основной Функционал

<table>
<tr>
<td width="50%">

### 💻 Cyberpunk Bootloader
Анимированный терминал загрузки `MONOLITH_OS_BOOT` с бегущими hex-символами по бокам, прогресс-баром и эффектами неонового свечения. Плавное затухание при переходе к основному интерфейсу.

</td>
<td width="50%">

### 🧠 ИИ-Ассистент Atlas
Локальный аналитический модуль, генерирующий контекстные подсказки в реальном времени — предупреждения об аномальных тратах, анализ долгового баланса, стратегия по целям.

</td>
</tr>
<tr>
<td width="50%">

### 📥 Учёт транзакций
Интуитивное переключение режимов **«Доход» / «Расход»** с динамической изоляцией списков категорий. Экспорт в **CSV** и **PDF** в один клик.

</td>
<td width="50%">

### 📊 Интерактивная Аналитика
Динамические круговые диаграммы на базе *Microcharts / SkiaSharp*. Нажатие на диаграмму открывает детальный breakdown по категориям с прогресс-барами.

</td>
</tr>
<tr>
<td width="50%">

### 🎯 Цели и Копилки
Визуальный трекер накоплений с `ProgressBar` и мгновенным пополнением через `🚀`. Atlas рассчитывает стратегию достижения цели.

</td>
<td width="50%">

### 💳 Менеджер Подписок
Контроль регулярных списаний с точной датой платежа. Atlas предупреждает об избыточных расходах на подписки.

</td>
</tr>
<tr>
<td width="50%">

### 💀 Debt Tracker
Секретная панель — открывается по нажатию на логотип. Раздельный учёт «мне должны» / «я должен». При закрытии долга баланс обновляется автоматически.

</td>
<td width="50%">

### 💱 Мультивалютное ядро
Интеграция с внешним API для пересчёта баланса в **RUB / USD / EUR** в реальном времени.

</td>
</tr>
<tr>
<td width="50%">

### 🔥 Стрик активности
Счётчик дней подряд с активностью. Отображается в хедере рядом с часами. Пропустил день — стрик сбрасывается.

</td>
<td width="50%">

### 🏆 Геймификация
Система достижений с разблокируемыми ачивками, уровнями и скрытыми наградами за финансовую дисциплину.

</td>
</tr>
<tr>
<td width="50%">

### 📝 Личный Журнал
Мини-блокнот в конце главной страницы для быстрых заметок. Автосохранение при потере фокуса.

</td>
<td width="50%">

### 🔐 Шифрование базы
SQLite база данных зашифрована через SQLCipher. Твои финансовые данные защищены даже при физическом доступе к устройству.

</td>
</tr>
</table>

## 🚀 Установка и Запуск

### Требования

<p>
  <img src="https://img.shields.io/badge/Visual%20Studio-2022+-5C2D91?style=flat-square&logo=visualstudio&logoColor=white"/>
  <img src="https://img.shields.io/badge/.NET%20SDK-9.0-512BD4?style=flat-square&logo=dotnet&logoColor=white"/>
  <img src="https://img.shields.io/badge/Xcode-required%20for%20Apple-1575F9?style=flat-square&logo=xcode&logoColor=white"/>
</p>

```bash
# 📥 Клонировать репозиторий
git clone https://github.com/Ph0biS/Monolith.git
cd Monolith

# 🔧 Восстановить зависимости
dotnet restore PROJECT.csproj

# 🖥️ Запуск на Windows
dotnet run PROJECT.csproj -f net9.0-windows10.0.19041.0

# 🍎 Запуск на macOS
dotnet build PROJECT.csproj -t:Run -f net9.0-maccatalyst

# 📱 Сборка для iOS (симулятор, только на Mac)
dotnet build PROJECT.csproj -t:Run -f net9.0-ios -p:RuntimeIdentifier=iossimulator-arm64

# 🤖 Сборка для Android
dotnet build PROJECT.csproj -f net9.0-android
```

### Self-Contained сборка для Windows (без установки .NET)

```bash
dotnet publish PROJECT.csproj -f net9.0-windows10.0.19041.0 -c Release -p:WindowsPackageType=None --self-contained true
```

> 📦 Готовый архив лежит в `bin\Release\net9.0-windows10.0.19041.0\win10-x64\publish\`
