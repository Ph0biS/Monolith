## ⚡ Основной Функционал (Core Features)

* **💻 Cyberpunk UI & Bootloader**
  Кастомная оболочка с анимированным терминалом загрузки (`MONOLITH_OS_BOOT`), эффектами неонового свечения (Neon Glow) элементов управления и глубокой темной темой.
* **📥 Раздельный учет транзакций**
  Интуитивное переключение режимов «Доход» / «Расход» с динамической изоляцией списков категорий для предотвращения ошибок ввода.
* **🧠 ИИ-Ассистент Atlas**
  Локальный аналитический модуль, генерирующий контекстные подсказки, предупреждения об аномальных тратах и подбадривающий пользователя при достижении целей.
* **📊 Интерактивная Аналитика**
  Динамические круговые диаграммы (*Microcharts / SkiaSharp*) с консистентным кодированием цветов (цвета на графике полностью совпадают с прогресс-барами и списками).
* **🎯 Цели и Копилки**
  Визуальный трекер сбережений с индикаторами выполнения (`ProgressBar`) и возможностью мгновенного пополнения ракетным депозитом `🚀`.
* **💳 Менеджер Подписок**
  Контроль регулярных списаний (сервисы, софт, связь) с отображением точной даты платежа в формате `dd/MM`.
* **💱 Мультивалютное ядро**
  Интеграция с внешним API курсов валют для мгновенного пересчета баланса (RUB, USD, EUR) в реальном времени.
