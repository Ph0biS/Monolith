## ⚡ Основной Функционал

### 💻 Cyberpunk Bootloader
Анимированный терминал загрузки (`MONOLITH_OS_BOOT`) с бегущими hex-символами по бокам, прогресс-баром и эффектами неонового свечения. Плавное затухание при переходе к основному интерфейсу.

### 📥 Учёт транзакций
Интуитивное переключение режимов **«Доход» / «Расход»** с динамической изоляцией списков категорий. Визуальная подсветка активного режима. Экспорт в **CSV** и **PDF**.

### 🧠 ИИ-Ассистент Atlas
Локальный аналитический модуль, генерирующий контекстные подсказки в реальном времени — предупреждения об аномальных тратах, анализ долгового баланса, стратегия по целям.

### 📊 Интерактивная Аналитика
Динамические круговые диаграммы на базе *Microcharts / SkiaSharp* с консистентным цветовым кодированием. Нажатие на диаграмму открывает детальный breakdown по категориям.

### 🎯 Цели и Копилки
Визуальный трекер накоплений с `ProgressBar` и мгновенным пополнением через кнопку `🚀`. Atlas отслеживает прогресс и рассчитывает стратегию достижения цели.

### 💳 Менеджер Подписок
Контроль регулярных списаний с точной датой платежа. Atlas анализирует суммарную нагрузку и предупреждает об избыточных расходах на подписки.

### 💀 Debt Tracker
Секретная панель трекера долгов — открывается по нажатию на логотип. Раздельный учёт «мне должны» / «я должен». При закрытии долга автоматически создаётся транзакция и обновляется баланс.

### 📝 Личный Журнал
Мини-блокнот в конце главной страницы для быстрых заметок. Автосохранение при потере фокуса.

### 🔥 Стрик активности
Счётчик дней подряд с активностью в приложении. Отображается в хедере рядом с часами. Пропустил день — стрик сбрасывается.

### 💱 Мультивалютное ядро
Интеграция с внешним API для пересчёта баланса в **RUB / USD / EUR** в реальном времени.

### 🏆 Геймификация
Система достижений с разблокируемыми ачивками, уровнями и скрытыми наградами за финансовую дисциплину.

## 🚀 Установка и Запуск

### Требования

- **IDE:** Visual Studio 2022+ с рабочей нагрузкой `.NET MAUI` **или** VS Code с расширением `.NET MAUI`
- **SDK:** `.NET SDK 9.0`
- **Для Apple:** Mac с актуальным **Xcode** (обязательно для iOS/macOS)

### Клонирование и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/Ph0biS/Monolith.git
cd Monolith

# Восстановить зависимости
dotnet restore PROJECT.csproj

# Запуск на Windows
dotnet run PROJECT.csproj -f net9.0-windows10.0.19041.0

# Запуск на macOS
dotnet run PROJECT.csproj -f net9.0-maccatalyst

# Сборка для Android
dotnet build PROJECT.csproj -f net9.0-android

# Сборка для iOS (только на Mac)
dotnet build PROJECT.csproj -f net9.0-ios -r iossimulator-arm64
```

### Кросс-платформенная сборка

```bash
# Только на Windows (все платформы кроме iOS/macOS)
dotnet build PROJECT.csproj

# Только на Mac (без Windows)
dotnet build PROJECT.csproj
# TargetFrameworks автоматически исключает Windows на не-Windows системах
```

## 📖 Инструкция Оператора

1. **Загрузка:** Дождитесь завершения анимации `MONOLITH_OS_BOOT`. Hex-колонки по бокам мигают — система инициализируется.

2. **Транзакции:** Нажмите `💸 РАСХОД` или `💰 ДОХОД` — активируется контекстный список категорий. Введите сумму и нажмите `ДОБАВИТЬ ЗАПИСЬ`.

3. **Копилки:** Создайте цель → пополняйте через `🚀` → Atlas отслеживает прогресс и советует стратегию.

4. **Долги:** Нажмите на логотип **MONOLITH** в хедере → откроется `💀 DEBT TRACKER`. Добавляйте долги, закрывайте — баланс обновляется автоматически.

5. **Аналитика:** Нажмите на диаграмму → детальный breakdown расходов по категориям с прогресс-барами.

6. **Экспорт:** Кнопки `📥 CSV` и `📄 PDF` рядом с балансом — полный финансовый отчёт в один клик.
